## About The Project

**Expert Partner AI** is a **19-slide interactive pitch deck** built entirely
with React.

It presents an **AI-powered career platform** designed to help developers
move from being stuck in the job market to becoming confident,
job-ready professionals.

Rather than behaving like a traditional slideshow, every slide is implemented
as a real React component with interactive navigation, animations, responsive
layouts, and live product demonstrations.

> We are not just preparing developers. We are building the bridge between
> talent and opportunity.

# Product Story

The deck communicates the idea behind an AI-powered career platform through a
structured narrative.

### Career Challenges

Developers often face uncertainty around:

* Career direction
* CV quality
* Finding relevant opportunities
* Interview preparation
* Understanding skill gaps

### AI-Powered Solution

Expert Partner AI addresses these challenges through a connected ecosystem
including:

* CV Analysis
* Career Path Recommendations
* Job Matching
* Mock Interviews
* Career Dashboard
* Credits System
* Administrative Tools

---

# Live Product Demonstrations

One of the main ideas behind the presentation is to avoid turning the pitch
into a collection of static screenshots.

Instead, selected slides embed actual product interfaces directly into the
presentation.

```text
Presentation
     |
     v
Interactive Slide
     |
     v
Live iframe
     |
     v
Actual Product Interface
     |
     v
Real Feature Demonstration
```

This makes the presentation itself part of the product experience.

```text
expert-partner-ai-deck
|
+-- src
|   |

|   |     Main presentation engine
|   |
|   +-- index.css
|   |     Animations
|   |     Glassmorphism
|   |     Gradients
|   |     Layout system
|   |
|   +-- main.jsx
|         React entry point
|
+-- public
|
+-- package.json
|
+-- README.md
```

---

# Deck Engine

The presentation is driven by a single `slidesData` array.

Each slide defines its layout type and content.

```js
{
  id: 20,
  type: 'split',
  title: 'Your New Feature',
  subtitle: 'A short description of the feature.',
  points: [
    'Point one',
    'Point two',
    'Point three'
  ],
  iframe: 'https://your-live-demo-url.com'
}
```

A standard slide can therefore be added by creating a new object rather than
building an entirely new component.

Supported slide types include:

```text
title
split
image
pillars
table
vision
```

# Project Goals

The project was designed around several key goals:

* Create a presentation that feels like a product
* Replace static presentation behavior with real interaction
* Demonstrate the actual product inside the pitch
* Create a memorable visual experience
* Keep the architecture simple and maintainable
* Support keyboard-first navigation
* Make the presentation responsive
* Communicate the AI career platform clearly

# Getting Started

## Prerequisites

```bash
node >= 18.x
npm >= 9.x
```

## Installation

```bash
git clone https://github.com/<your-username>/expert-partner-ai-deck.git
```

```bash
cd expert-partner-ai-deck
```

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

The application will be available through the local development URL provided
by your environment.

---

# Build For Production

```bash
npm run build
```
